# 合成配方冲突选择器

适用原版背包2×2与工作台3×3。服务器按真实网格、配方ID和个人权限计算全部可制作候选；两个及以上时结果槽下方显示选择按钮。选择仅更新预览，取出才消耗。

- 选中配方负责产物数量/NBT及余料，保留原版合成事件和统计。
- Shift一次操作锁定该配方ID，每批重新验证；不会切换另一条同产物配方。背包装不下完整一批时停止。
- 输入改变仍合法时保留选择；失效后按配方ID稳定选择。权限和配方重载会重新验证。
- 请求携带菜单ID、会话、输入版本和递增序号；服务端校验真实菜单、距离、材料和权限，不能上传权限列表。
- 内置浏览器＋填充同时选择目标ID。原版配方书转移路径亦接入；仓库未安装外部JEI，不宣称验证其自有转移协议。
- 独立模态Screen在容器/浏览器之后绘制不透明弹窗，外部点击只关闭、Esc优先关闭，tooltip在弹窗上方。界面和GUI缩放均待用户验证。
- 特殊第三方菜单子类保留其原有结算，不强行接管自定义消耗逻辑。客户端和服务端须同时更新新JAR（新增独立网络通道）。

## 文件

`crafting_choice.java`：权威候选/选择/Shift状态；`crafting_choice_network.java`：定向协议；`crafting_choice_layout.java`：布局边界；`crafting_choice_client.java`：按钮和模态窗口。三个Mixin分别接入原版点击作用域、选中余料、配方书填充；既有预览与研究门控复用。

## 手动验证

正式配方不为测试而修改。可选包、安装/授权命令及两组案例见[独立测试包说明](test-datapacks/README-冲突选择器手动测试.md)。数据包不包含在正式JAR、不自动安装到存档。

测试涵盖切换、Shift锁定、普通取出和数字键、返瓶差异、浏览器填充、遮挡/点击穿透、Esc、GUI缩放及小窗口；后几项为用户游戏内验收，自动测试不能代替。
