## 2. 简易铁工具

- 独立物品注册，不是预扣耐久的普通铁工具。
- 采掘等级、采掘速度、攻击伤害、攻击速度、附魔能力均复用铁材料；每件工具构造时读取对应正规铁工具的实际最大耐久并除以 3，向下取整、至少 1。
- 当前对应正规铁工具最大耐久均为 250，因此实际最大耐久均为 **83**。这不是写死 83：代码分别读取 `Items.IRON_PICKAXE/AXE/SHOVEL/HOE/SWORD` 的 `getMaxDamage()/3`。
- 修复材料为铁锭；铁砧修理、砂轮合并仍是同一独立物品，不会变成正规铁工具，也不会突破自身最大耐久。
- 工具配方 ID 与物品 ID 相同：
  - `white_lily:makeshift_iron_pickaxe`
  - `white_lily:makeshift_iron_axe`
  - `white_lily:makeshift_iron_shovel`
  - `white_lily:makeshift_iron_hoe`
  - `white_lily:makeshift_iron_sword`
- 5 条配方材料、数量、形状与对应原版铁工具一致；正规铁工具原配方保留。两套配方使用不同稳定 ID，由现有同材料配方选择器按权限展示和切换。

解锁条件（全部为历史/权限，不消耗物品）：

| 产物 | 条件 |
|---|---|
| 简易铁镐 | 已掌握木镐 + 已掌握石镐 + 已获得过铁锭 |
| 简易铁斧 | 已掌握木斧 + 已掌握石斧 + 已获得过铁锭 |
| 简易铁锹 | 已掌握木锹 + 已掌握石锹 + 已获得过铁锭 |
| 简易铁锄 | 已掌握木锄 + 已掌握石锄 + 已获得过铁锭 |
| 简易铁剑 | 已掌握木剑 + 已掌握石剑 + 已获得过铁锭 |

“已掌握”读取真实制作权限；“铁锭”读取持久化获得历史。条件顺序不限，最后一项满足时补发。仅获得铁锭不会开放 5 件简易工具，也不会开放正规铁工具。

## 3. 七种知识书

固定书：

| 书 | 阅读后授予 |
|---|---|
| 配方书-盾牌 | `minecraft:shield` |
| 工匠手记·切石机 | `minecraft:stonecutter` + `white_lily:operation/stonecutter` |
| 铁匠手记·锻造 | `minecraft:anvil` + `white_lily:operation/anvil` |
| 工匠手记·装备改造 | `minecraft:smithing_table`（不授予具体锻造升级/纹饰） |
| 工匠手记·运输 | `minecraft:rail` + `minecraft:minecart` |

随机书（服务端均匀随机，只从“存在、当前有效、尚未掌握”的目标中选择一种）：

- 铁匠手记·工具：铁镐、铁斧、铁锹、铁锄、铁剑，共 5 类。
- 铁匠手记·防具：铁头盔、铁胸甲、铁护腿、铁靴子，共 4 类。

阅读规则复用现有 `recipe_unlock_book` 服务端流程：

- 生存首次成功学习消耗 1 本；没有新增知识时不消耗，并提示已掌握。
- 创造成功学习不消耗。
- 目标不存在/当前无效时不消耗。
- 随机书一次请求只学一种，不把结果写入物品 NBT；同一本书的副本仍按当前使用者进度随机。
- 10 刻使用冷却，服务端权威，阻止主副手连续重复请求。
- 阅读不要求先拥有铁锭，制作仍要求实际材料。

## 4. 抄录配方

7 本新书各有 1 条抄录配方，均为无序合成：

```
原书 ×1 + minecraft:book ×1 + minecraft:ink_sac ×1 + minecraft:feather ×1
→ 同种知识书 ×1
```

配方 ID：

- `white_lily:blacksmith_tools_notes_copy`
- `white_lily:blacksmith_armor_notes_copy`
- `white_lily:shield_recipe_book_copy`
- `white_lily:stonecutter_notes_copy`
- `white_lily:blacksmith_forging_notes_copy`
- `white_lily:equipment_upgrade_notes_copy`
- `white_lily:transport_notes_copy`

行为：

- 使用专用 `white_lily:template_copy` 配方序列化器，仅这些抄录配方返还原书；书物品本身没有全局 crafting remainder。
- 原书原样返还一份，保留自定义名称和 NBT；新副本是普通同种书，不复制模板状态、不预固定随机结果。
- 仅消耗普通书、墨囊、羽毛；原书作为模板不消耗。
- 普通取出、Shift、批量制作均由原版结果槽与现有选择器服务端处理；满背包时不吞模板或材料。
- 抄录不触发阅读，不授予书中知识。
- 获得某本书时，通过 `on_pickup` 只授予该书的抄录配方，不全局放开其他配方。抄录配方本身仍要求原书作为材料，因此没有模板时无法实际制作。
- 现有“配方书-金剑”不加入本轮抄录。

## 5. 铁器日用品路线

配置位置：`src/main/resources/data/white_lily/recipe_unlocks/defaults.json`。

| 条件 | 授予 |
|---|---|
| 获得铁锭 | 铁粒↔铁锭、铁锭↔铁块的 4 条正常压缩/拆分配方（配方类型限 crafting，输入/产物同时限铁锭/铁粒/铁块） |
| 铁锭 + 线 | 剪刀 |
| 铁锭 + 燧石 | 打火石 |
| 铁锭 + 碗 | 桶 |
| 获得桶 | 炼药锅 |
| 铁锭 + 已掌握任意木板制作 | 铁栏杆、锁链 |
| 铁锭 + 已掌握任意一种木门制作 | 铁门 |
| 铁锭 + 已掌握任意一种木活板门制作 | 铁活板门 |
| 铁锭 + 火把 | 普通灯笼（不是铁粒） |
| 已掌握普通灯笼 + 灵魂火把 | 灵魂灯笼（本轮不补灵魂火把自身路线） |
| 已掌握普通矿车 + 箱子 | 运输矿车（箱子矿车） |
| 铁锭 + 红石 | 指南针 |

未加入漏斗、活塞、弩、探测/动力/激活铁轨、漏斗矿车、TNT 矿车等未确认路线。

## 6. 组合条件通用扩展

`recipe_unlock_rules` 的 `conditional` 在原有 `seen`、`unlocked` 之外新增：

- `unlocked_outputs`：玩家已解锁的任意一条真实配方的产物匹配选择器即可。用于“任意一种木门/木活板门/木板制作”而不用列出所有树种。
- 仍保留 `unlocked` 的精确配方 AND 条件。
- `recipe_unlocks.evaluateConditional` 在初始化、获得物品、显式解锁和配置重载时运行，最多 16 轮收敛；不在每 tick 扫描全部配方。
- `generation` 使用规则文件内容签名；规则变化后旧玩家登录会重新评估已有 `seen` 历史。

## 7. 设备操作权限

- 切石机书同时授予 `minecraft:stonecutter` 制作和 `white_lily:operation/stonecutter`。`recipe_menu_gate` 对 Stonecutter 结果槽同时检查设备 operation 与当前具体切石配方的个人权限；普通取出和 Shift 都经过同一检查。
- 锻造书同时授予 `minecraft:anvil` 和 `white_lily:operation/anvil`；沿用现有铁砧结果槽检查，不新增开裂/损坏铁砧配方。
- 装备改造书只授予 `minecraft:smithing_table`，不授予锻造升级配方，也不新增锻造台 operation。
- 未新增其他设备 operation。

## 10. 悬停说明

12 件新物品均接入现有石制研钵同款“按住 Shift 查看详细介绍”：

- 未按 Shift：只显示统一提示，工具简介/耐久、书的学习方式/目标/抄录说明全部折叠；物品名、创造栏和模组等正常提示保留。
- 按住 Shift：工具按原顺序展开简介与三分之一耐久说明；知识书依次展开学习方式、目标内容和抄录规则。
- 金剑书保持原有常显说明，不套用本轮折叠，也不追加抄录说明。
- 原版攻击伤害、攻击速度、附魔、耐久等自动提示不参与折叠，也没有被删除或重复。
- Shift 判断和提示文案复用 `detail_tooltip`，未另写一套逻辑。

客户端实际悬停、换行与左右 Shift 表现**待用户验证**。
