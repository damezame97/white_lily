# 麻与基础材料加工

## 六种最终配方

| 产物 | 材料 | 数量与方式 |
|---|---|---|
| 粗布片 | 麻秆 ×3 | 水平单行，可放合成台任意一行；产出2 |
| 细布条 | 粗布片 ×1、原版剪刀 ×1 | 无序；产出3；剪刀损伤1 |
| 软木塞 | 允许的带皮原木 ×1、原版剪刀 ×1 | 无序；产出8；剪刀损伤1 |
| 蜂蜡块 | 蜜脾 ×1、蜂蜜瓶 ×1 | 无序；产出3；返还1玻璃瓶 |
| 炭粉 | 木炭 ×1 | 无序；产出4；不接受煤炭 |
| 空白标签 | 纸 ×1、线 ×1 | 无序；产出4 |

剪刀加工共用 `white_lily:durable_tool_shapeless`。配方预览不修改输入；原版 ResultSlot 在取走结果时读取余料，返还完整复制NBT、损伤增加1的剪刀。忽略耐久附魔的免损概率，最后一点耐久仍能加工并使剪刀消失。不修改其他剪刀用途。

`data/white_lily/tags/items/cork_logs.json` 明确列出橡木、云杉、白桦、丛林、金合欢、深色橡木、红树、樱花原木。未使用宽泛 logs 标签。

仓库原来没有这六种材料的配方文件；没有发现需要删除的四线织布、无剪刀切布、单蜜脾制蜡等旧配方。加载中的前置配方是否冲突由 HempGameTests 实际枚举匹配结果检查，测试日志记录具体冲突ID。

## 种植与生成

- `white_lily:hemp_seeds` 麻籽，堆叠64；仅种在耕地上。
- `white_lily:hemp_stalk` 麻秆，堆叠64；普通材料，不能种植。
- `white_lily:hemp_crop` 四阶段作物，age=0/1/2/3。随机刻沿用小麦的光照、耕地肥沃度与邻株生长计算，每次阶段增长额外以3/7通过，使三个阶段增长的总体期望与小麦七次增长相近。骨粉按阶段比例促进生长，成熟后不能复制。
- `white_lily:wild_hemp` 独立成熟野生植株，没有独立物品注册，不暴露无用途的创造栏方块物品。只接受野生麻土壤标签中的草方块、泥土，不接受骨粉，不生长或蔓延。
- 成熟作物和野生植株：麻秆均匀随机2～3，麻籽均匀随机1～2；未成熟作物只掉1麻籽。统一由掉落表处理，不添加时运加成。
- 复用已有 `white_lily:herb_patch` 有界 Feature，新配置 `white_lily:hemp_patch`：每区块一次10%判定，均匀目标2～4株，最多32次落点尝试，全部限制在当前区块；重复调用按区块与植物ID去重。
- 默认平原、向日葵平原、森林、桦木森林；只在新生成的主世界露天地表。群系标签 `data/white_lily/tags/worldgen/biome/hemp_habitats.json`，土壤标签 `data/white_lily/tags/blocks/wild_hemp_soils.json`。

## 获取与测试

```mcfunction
/give @s white_lily:hemp_seeds 64
/give @s white_lily:hemp_stalk 64
/give @s white_lily:coarse_cloth 64
/give @s white_lily:thin_cloth_strip 64
/give @s white_lily:cork_stopper 64
/give @s white_lily:beeswax_block 64
/give @s white_lily:charcoal_powder 64
/give @s white_lily:blank_label 64
/setblock ~ ~-1 ~ minecraft:farmland
/setblock ~ ~ ~ white_lily:hemp_crop[age=3]
/place feature white_lily:hemp_patch
/recipe give @s white_lily:thin_cloth_strip
```

`/place feature` 仍受主世界、群系、区块去重、概率等约束，并不保证每次手动调用都生成。测试野生麻可先放泥土再 `/setblock ~ ~ ~ white_lily:wild_hemp`。自然生成只需在新探索区块观察；不对旧区块补种。
