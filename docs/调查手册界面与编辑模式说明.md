# 调查手册：档案界面与编辑模式

本轮沿用已有个人研究、保存和花茶制作权限，没有添加研究节点、修改药效、材料或配方，也没有开启植物自然生成。

## 操作

- 手持调查手册右键，或使用生存/创造背包左上角的手册按钮。
- 栏目可展开为文字及章节，或收窄为图标；详情可使用固定侧栏或覆盖面板。偏好保存到客户端 `config/white_lily-research-ui.json`，不进入玩家研究进度或手册NBT。
- 小窗口临时改用图标栏和覆盖详情，底部空间不足时合并显示设置或换行；不会覆盖保存的首选模式。
- 树区域滚轮缩放10%～200%，以鼠标所指研究坐标为中心。点击百分比回到100%；恢复视图将当前章节的可见节点居中，编辑模式包含当前章节全部节点。
- 50%以上显示名称、图标和状态；25%～不足50%隐藏常驻名称；低于25%使用状态标记。悬停说明使用正常字号。
- 左键拖动空白处平移；左键或右键单击空白处关闭详情。移动达到4个GUI像素后按拖动处理，不关闭详情。详情和栏目各自滚动。
- 右键菜单优先接收输入；点击菜单外只关闭菜单。切换章节、布局变化、拖动和关闭界面会清理失效菜单。

## 检查背包

点击“检查背包”让服务端核对自己的背包，不消耗物品，不检查周围掉落物或箱子。每次只处理检查开始时已揭示且满足前置的“获得物品”节点，不连锁展开，也不代替花茶的材料提交。20刻冷却防止重复请求。

正常路线保持：获得安神花 → 发现节点完成并揭示花茶 → 提交安神花1＋空白标签1 → 开放已有花茶配方。制作另需安神花2＋普通水瓶1。

## 管理员编辑

仅服务端命令权限等级2可用；创造模式本身不授权。编辑只影响自己，每次请求重新检查权限和进度版本。重新打开界面时编辑默认关闭。

进入后能看到实际配置但尚未揭示的节点；查看并不解锁，也不会发放物品。右键节点：

- **直接完成**：补齐必要前置，不完成无关分支，不扣材料、不发成品。
- **重置为未解锁**：连带重置失去必要依赖的后续节点，立即撤销对应配方书和实际制作权限。不删除既有成品，不返还历史研究材料。
- 菜单显示服务端计算的影响范围；重复完成、无意义重置禁用。

重置发现节点会保存已有数量基线。旧库存、纯背包格/光标/自身合成格移动、重登、打开界面不自动撤销重置。新的实际拾取/制作/熔炼事件及后续库存净新增可以重新发现；主动“检查背包”明确允许重新发现。背包检查仍不能跳过前置或提交条件。

获取手册：`/give @s white_lily:investigation_handbook`。测试花茶：先获取安神花和空白标签，按上述路线操作；管理员也可直接完成花茶以检查前置补齐，然后重置安神花检查连带撤销。
