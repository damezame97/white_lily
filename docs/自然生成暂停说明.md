# 植物自然生成暂停

2026-10-23：按用户要求，暂时关闭苦叶草、止血蓍草、安神花和野生麻的自然生成，等待与作者的新群系统一安排。

四份 `data/white_lily/forge/biome_modifier/add_*.json` 使用 Forge 自带的 `forge:none`，不再向群系添加植物 feature。保留原修饰器 ID，避免数据注册表键被删除。原 configured_feature、placed_feature、栖息地标签、概率、数量和放置逻辑保持原样。

重启游戏或服务器、加载新版模组后，后续生成的新区块不再自然生成这四种植物。已生成的植物不会清除；人工放置、种植、骨粉规则、掉落和合成配方不受此改动影响。手动 `/place feature` 仍可调用保留的 feature；外部数据包也可重新启用，因此此处仅保证模组默认资源关闭自然生成。

未来恢复时，把相应修饰器替换为以下结构（`<name>` 分别为 `bitterleaf`、`yarrow`、`calming_flower`、`hemp`），或按作者统一方案接入新的群系：

```json
{
  "type": "forge:add_features",
  "biomes": "#white_lily:<name>_habitats",
  "step": "vegetal_decoration",
  "features": "white_lily:<name>_patch"
}
```

恢复时同步更新 `MedicalWorldgenGameTests` 和 `HempWorldgenGameTests` 的群系挂载断言。当前测试仍核对保留的概率、上限和手动放置行为，并检查全部已加载群系均未挂载上述四种 feature。
