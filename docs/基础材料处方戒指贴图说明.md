# 基础材料、处方与戒指贴图重绘

本次使用内置 image_gen 为九件现有物品逐件重绘贴图，不改变注册 ID、名称、配方或行为。完整提示词和生成来源见同目录 `基础材料处方戒指贴图重绘记录.json`。

统一采用接近原版 Minecraft 的低分辨率像素风格、有限色调、硬边像素轮廓。根据生成图的透明通道裁掉外部空白，保持比例，用最近邻缩至最多 14×14 的主体，居中放入实际 16×16 RGBA 画布。透明度为 0 或 255，四周至少留一像素边距；未使用平滑采样。

## 预览与备份

- 放大预览：`docs/previews/basic_materials_prescriptions_ring_16x.png`。棋盘格仅为预览底色，不在物品 PNG 中。
- 替换前的九张贴图：`build/texture-backup-basic-20261022/`。该目录被 Git 忽略，是本机备份，清理 build 前请另行保存。
- 内置工具生成的原始大图保留在生成记录中的源路径，没有覆盖原图。

## 验证

- 已逐件检查成品尺寸、RGBA 模式、二值透明通道、一像素边距以及模型 layer0 引用。
- 已查看九张成品的最近邻放大预览。
- `gradlew build` 构建通过；最终 `white_lily-0.1.2.jar` 内九张 PNG 与源文件逐字节一致，尺寸及模式检查通过。
- 本次仅替换资源，没有新增玩法测试；未在客户端实际查看背包、手持或掉落物渲染。

## 自行替换

使用同名 PNG 替换上述资源目录中的文件即可；保持名称不变时，无须更改模型 JSON 或 Java。运行中的开发客户端可用 F3+T 重载资源；启动器中的模组需重新构建，并替换对应实例 mods 文件夹中的旧版模组 JAR。
