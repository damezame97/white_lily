# 配方浏览器：同类聚集与名称排序

本轮只改客户端排序、分类配置和原分页算法的可测调用；未修改配方、解锁权限、机器上下文或浏览器布局。全部客户端画面 **待用户验证**。

## 三种模式

- **默认**：跨模组按当前语言的类别名称排序，再按物品显示名排序。同类聚集，模组不参与组顺序。类别名仅作内部排序键，不显示标题，不换行或占空格。
- **名称**：忽略类别和模组，只按物品显示名排序。
- **模组分类**：按物品namespace分组，Minecraft在前，其余按实际模组显示名（空值回退namespace）；模组内部按类别名、物品名排序。只保留既有模组标题。

中文名称/类别名称都使用Java17简体中文Collator，已用实际阿/八/陈/李/王/张/赵顺序及木板/原木排序测试核对；英文忽略基本大小写，去除格式字符而不修改物品本身。相同名称用注册ID及现有NBT变体键稳定破平。类别翻译同名时再用类别稳定ID保持主类别连续。未匹配物品以自己的显示名作为类别键，不集中到“其他”。多音字采用JDK排序表，不做语义分词。

## 分类资源与优先级

文件：`assets/white_lily/recipe_browser/categories.json`（源码位于`src/main/resources/`）。客户端资源包可以覆盖同路径文件；**不是服务器数据包，也不影响权限**。

`rules`数组从上到下，首个匹配生效。每条规则的`items`、`tags`、`kinds`是“或”关系；缺少的选择器可省略。不能靠物品的第一个标签或中文名称判断。

默认优先级（这是匹配优先级，不是最终组显示顺序）：

1. 药草：苦叶草、止血蓍草、安神花明确ID。
2. 医疗用品：两种绷带、药膏、敷料、花茶、低质量药剂及原版三种药水载体ID，先于食物。
3. 加工工具：石制研钵、简易加工台明确ID。
4. 原木：`minecraft:logs`，包含正确打标签的去皮原木、菌柄、第三方木材；不使用燃料或所有方块作替代。
5. 木板：`minecraft:planks`。
6. 台阶 → 楼梯 → 门 → 活板门 → 按钮 → 压力板 → 栅栏 → 栅栏门：语义标签及对应方块类型补充。
7. 矿石 → 金属粒 → 金属锭 → 宝石 → 粉末：Forge对应`ores/nuggets/ingots/gems/dusts`标签；本模组炭粉明确补充粉末。
8. 护甲：Forge标签与ArmorItem；武器：剑/弓/弩/三叉戟标签与类型，以及TaCZ真实`modern_kinetic_gun` ID；工具：Forge通用工具标签及挖掘工具、剪刀、钓竿、打火石类型。武器先于宽泛工具匹配。
9. 基础材料：项目现有布料、木塞、蜂蜡、标签、麻籽/秆、纤维、托盘、碗、细管、滤片、干燥剂、残渣、布包和处方明确ID。
10. 食物：可食用属性补充。

标签存在但当前没有成员时视为不匹配，方便资源包/第三方扩展；不会枚举标签后随便取第一个。不存在的显式物品ID会记录文件与规则位置警告，不能匹配任何物品。

### 后续新增方法

优先补入已有类别的`items`或语义明确`tags`；新类别则新增规则，并加入中英文键`screen.white_lily.recipe_browser.sort_category.<category>`。例如给新药草补已有herbs规则的items，不需要改Screen。枪械以真实物品载体ID或语义明确标签加入weapons，不能把整个模组namespace归为武器。共享枪械载体的不同NBT枪械仍各自保留。

```json
{"category":"herbs","items":["white_lily:bitterleaf","your_mod:new_herb"],"tags":["your_mod:medicinal_herbs"]}
```

新增类别的优先级由数组位置决定，最终类别顺序则由类别当前语言名称决定。资源包覆盖文件时需保留其他需要的规则；不是逐文件自动合并。

## 加载、缓存与分页

- 客户端首次资源加载/F3+T重载解析规则；错误规则单独跳过并定位`categories.json: rules[index]`，整个文件损坏安全回退物品名称，不使浏览器崩溃。
- 分类缓存按Item保存（当前选择器不依赖NBT）；不同NBT变体的名称/ID/NBT排序键分别保留。标签更新会清分类缓存；资源重载会替换规则并使索引失效。
- 切换语言、物品集合、个人/机器/作弊上下文变化会重建排序缓存；不在每帧扫描所有标签或排序全表。
- 排序只接收已有真实可见物品，不按分类配置增加物品，不授予个人研究/机器登记/作弊权限。
- 搜索与收藏在排序后过滤；分页只占真实物品和模组标题。没有类别空位、空模组标题；切换模式尽量重新定位原页首项，无法定位则夹取合法页码。独立缩放与窄侧栏原样保留。
- 模式继续保存于`config/white_lily-recipe-browser.json`现有`sort`字段，不新增重复偏好文件。

## 用户验收（待用户验证）

1. 默认模式：原版与第三方原木相邻、木板相邻；类别不显示文字/空行，网格连续。
2. 名称模式：不再聚类，中文拼音/英文字母顺序正确；同名NBT变体不丢失。
3. 模组分类：Minecraft优先，每个模组内部同类聚集，只有模组标题占位。
4. 搜索、收藏、翻页和50/100/150%物品比例、窄侧栏保持正常；重开/重启记住模式。
5. 切换语言与F3+T后顺序刷新；关闭/换加工台后临时物品范围不扩大；作弊显示所有只在原权限允许时可用。
