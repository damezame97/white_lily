## 浸水显字

空白处方作为掉落物，连续接触 `minecraft:water` 流体标签中的水 40 个服务端游戏刻后，整组变为显字处方。正常 20 TPS 下为 2 秒；服务器卡顿时实际等待时间会更长。

使用 Forge 的单个物品实体更新钩子，不扫描整个世界。计时保存在每个掉落物实体自身，离水后清零。流体判断检查包围盒与水面的接触，支持水源和流动水，不使用雨水判定。

转换只替换同一个 ItemEntity 内的物品栈，保留数量、位置、运动速度、拾取延迟及归属，并继续运行原版实体更新。没有禁用合并、拾取或漏斗吸取。

## 水瓶合成

无序合成：一张空白处方 + 一瓶普通水瓶 → 一张显字处方，并返还一个玻璃瓶。背包的 2×2 合成格和合成台的 3×3 合成格都可使用。

配方文件：`src/main/resources/data/white_lily/recipes/revealed_prescription.json`。

- 使用 Forge 严格 NBT 配料匹配 `minecraft:potion` 和 `{Potion:"minecraft:water"}`，拒绝其他药水、喷溅/滞留水瓶，以及额外修改过 NBT 的水瓶。
- 自定义无序配方仅覆写余料处理；每消耗一个水瓶，返回一个空瓶，由原版 ResultSlot 分配到合成格、背包或地面。
- 水瓶在原版不能正常堆叠，所以常规操作是放入一瓶、Shift 合成、拿走空瓶后再补下一瓶。不能把多瓶水分放在多个格子当成一次配方。
- 若命令或其他模组提供堆叠水瓶，也按每次消耗一瓶、返回一个空瓶处理。
- 获得空白处方会通过配方进度解锁显字处方配方。

## 游戏内复现步骤

1. IDEA 选择 `runClient`，进入允许作弊的测试世界，执行：

   ```mcfunction
   /give @s white_lily:blank_prescription 64
   /give @s minecraft:potion{Potion:"minecraft:water"} 1
   /give @s minecraft:potion{Potion:"minecraft:healing"} 1
   ```

2. 将整组空白处方丢进水源或水流，等约 2 秒，拾取后检查为 64 张显字处方。
3. 另用一组空白处方做短时浸泡，提前拾起，确认仍为空白。要精确观察同一个实体离水清零，可将它推过一小段水、干地、再进入水；每次重新入水均应重新等待约 2 秒。
4. 在合成台任意两个格子放空白处方和普通水瓶，取出成品，确认空白处方与水瓶消耗，水瓶格留下一个空瓶。
5. 将水瓶换成治疗药水、喷溅水瓶、滞留水瓶，确认没有成品。
6. 连续补水瓶并 Shift 合成，核对每张显字处方对应一个空瓶；同时测试背包全满的情况。
7. 将转换后的处方丢在漏斗上，确认可以吸入。
8. 切换中文和英文，检查名称、描述、贴图显示与配方书解锁。

本次功能不修改 Mixin，不修改低质量药剂的类、模型、贴图或饮用行为，也没有新增药剂或药效。客户端显示、手工操作与真实多人联机仍需按上述步骤复核；自动测试不能替代这些检查。
