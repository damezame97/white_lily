## 1. 当前实际存在的浏览器快捷操作

以当前 `recipe_browser.java` 的代码为准：

| 操作 | 当前硬编码 | 作用范围 |
|---|---|---|
| 显示/隐藏浏览器侧栏 | `Ctrl+O` | 任意 `AbstractContainerScreen` 的浏览器面板 |
| 聚焦搜索 | `Ctrl+F` | 面板或独立浏览器页 |
| 查看悬停物品配方 | `R` | 面板悬停物或容器槽位；详情页悬停材料 |
| 查看悬停物品用途 | `U` | 同上 |
| 收藏/取消收藏 | `A` | 悬停物；详情页无悬停物时收藏当前产物 |
| 查询返回 | 鼠标中键、返回按钮 | 仅详情页有历史时 |
| 上一配方 | `←` / `PageUp` | 详情页 |
| 下一配方 | `→` / `PageDown` | 详情页 |

普通左键/右键用于打开配方/用途或鼠标点击；中键在列表/详情中用于收藏，在详情页中键也用于返回。**这些鼠标基本交互保留**。

## 3. 需要合入 `recipe_browser.java` 的改动

### 3.1 安装浏览器动作处理器

在 `recipe_browser` 类字段之后加：

```java
static
{
    recipe_browser_key_bridge.install(recipe_browser::handleShortcut);
}
```

并在 `open(...)` 附近加入：

```java
private static boolean handleShortcut(recipe_browser_key_bridge.Action action)
{
    Minecraft mc = Minecraft.getInstance();
    Screen screen = mc.screen;
    if (screen == null) return false;
    if (screen.getFocused() instanceof EditBox) return false;
    if (screen instanceof RecipeScreen details) return details.shortcut(action);
    if (screen instanceof BrowserScreen browser) return browser.shortcut(action);
    if (screen instanceof AbstractContainerScreen<?> container)
    {
        Panel current = panel(container);
        return current != null && current.shortcut(action);
    }
    return false;
}
```

### 3.2 `Panel` 增加动作入口

放在 `Panel` 内、`hovered()` 附近：

```java
boolean shortcut(recipe_browser_key_bridge.Action action)
{
    if (query.isFocused()) return false;
    switch (action)
    {
        case TOGGLE:
            collapsed = !collapsed;
            layout();
            return true;
        case SEARCH:
            if (compact) show(new BrowserScreen(parent));
            else query.setFocused(true);
            return true;
        case RECIPES:
        case USES:
        case FAVORITE:
            ItemStack stack = hovered();
            if (stack.isEmpty() && parent instanceof AbstractContainerScreen<?> container
                    && container.getSlotUnderMouse() != null)
                stack = container.getSlotUnderMouse().getItem();
            if (stack.isEmpty()) return false;
            if (action == recipe_browser_key_bridge.Action.RECIPES) open(parent, stack, false);
            else if (action == recipe_browser_key_bridge.Action.USES) open(parent, stack, true);
            else { recipe_browser_preferences.toggle(stack); refreshFilter(); }
            return true;
        default:
            return false;
    }
}
```

### 3.3 `BrowserScreen` 增加动作入口

放在 `BrowserScreen` 内、`keyPressed` 附近：

```java
boolean shortcut(recipe_browser_key_bridge.Action action)
{
    if (contents.query.isFocused()) return false;
    switch (action)
    {
        case SEARCH:
            contents.query.setFocused(true);
            return true;
        case RECIPES:
        case USES:
        case FAVORITE:
            ItemStack stack = contents.hovered();
            if (stack.isEmpty()) return false;
            if (action == recipe_browser_key_bridge.Action.RECIPES) open(this, stack, false);
            else if (action == recipe_browser_key_bridge.Action.USES) open(this, stack, true);
            else { recipe_browser_preferences.toggle(stack); contents.refreshFilter(); }
            return true;
        default:
            return false;
    }
}
```

### 3.4 `RecipeScreen` 增加动作入口

放在 `RecipeScreen` 内、`keyPressed` 附近：

```java
boolean shortcut(recipe_browser_key_bridge.Action action)
{
    switch (action)
    {
        case BACK:
            if (history.isEmpty()) return false;
            back();
            return true;
        case PREVIOUS:
            if (visible.size() <= 1) return false;
            change(-1);
            return true;
        case NEXT:
            if (visible.size() <= 1) return false;
            change(1);
            return true;
        case FAVORITE:
            if (!hoveredStack.isEmpty()) recipe_browser_preferences.toggle(hoveredStack);
            else toggleFavorite();
            select();
            return true;
        case RECIPES:
            if (hoveredStack.isEmpty()) return false;
            open(this, hoveredStack, false);
            return true;
        case USES:
            if (hoveredStack.isEmpty()) return false;
            open(this, hoveredStack, true);
            return true;
        default:
            return false;
    }
}
```

### 3.5 删除旧硬编码判断

删除后由 `white_lily_key_handler` 统一分发；不能保留两套并行判断。

1. 外层 `key(ScreenEvent.KeyPressed.Pre)`：保留输入框聚焦/`EditBox` 判断，删除 `Ctrl+O`、`Ctrl+F`、`R/U`、`A` 的分支。
2. `BrowserScreen.keyPressed`：保留输入框聚焦处理，删除 `Ctrl+F`、`R/U`、`A` 分支。
3. `RecipeScreen.keyPressed`：删除 `←/→/PageUp/PageDown`、`A`、`R/U` 分支，只保留 `super.keyPressed(...)`。

## 4. 动态提示替换

`white_lily_key_display.hint(...)` 读取实时 `KeyMapping.getTranslatedKeyMessage()`，包含修饰键、鼠标键和未绑定名称；不会读配置文件，也不会每帧重建索引。

按当前调用点替换：

| 当前调用 | 替换为 |
|---|---|
| `tr("item_controls")` | `white_lily_key_display.hint("item_controls.keys", BROWSER_RECIPES, BROWSER_USES, BROWSER_FAVORITE)` |
| `tr("open_hint")` | `white_lily_key_display.hint("open_hint.keys", BROWSER_TOGGLE, BROWSER_SEARCH)` |
| `tr("favorites")` | `white_lily_key_display.hint("favorites.keys", BROWSER_FAVORITE)` |
| `tr("search_help")` | `white_lily_key_display.hint("search_help.keys", BROWSER_SEARCH)` |
| `tr("detail_help")` | `white_lily_key_display.hint("detail_help.keys", BROWSER_PREVIOUS, BROWSER_NEXT)` |

对应语言键已经加入 `zh_cn.json` / `en_us.json`：

```text
screen.white_lily.recipe_browser.item_controls.keys
screen.white_lily.recipe_browser.open_hint.keys
screen.white_lily.recipe_browser.favorites.keys
screen.white_lily.recipe_browser.search_help.keys
screen.white_lily.recipe_browser.detail_help.keys
```

保留旧键给尚未合入的版本使用；合入后可以删除旧键，但不要在其他助手仍引用时删除。

## 5. 合入后的行为

- 只有浏览器动作处理器安装后，8 个浏览器 KeyMapping 才会动作。
- 旧 `R/U/A/←/→/PageUp/PageDown/Ctrl+O/Ctrl+F` 判断删除后，不会与新绑定重复触发。
- 搜索框聚焦时，`Panel/BrowserScreen.shortcut` 直接返回 false；`white_lily_key_handler` 也会在任意 `EditBox` 聚焦时提前返回，避免其他模组文本输入误触。
- 手册快捷键独立于浏览器，不依赖本补丁；默认未绑定。
- 鼠标点击、右键、中键收藏/返回、创造模式中键取物等原逻辑不改。
