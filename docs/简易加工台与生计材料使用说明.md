## 加工台操作

右键打开。左侧放研钵，中央三槽放原料，下方独立槽供配方指定容器使用；右侧依次为成品、返还和副产物。当前三条正式配方均不需要容器。

| 原料 | 成品 | 返还 | 副产物 | 时间 |
| --- | --- | --- | --- | --- |
| 麻秆×1 | 植物纤维×2 | 无 | 无 | 40刻，2秒 |
| 苦叶草×3 | 苦叶药膏×2 | 无 | 药草残渣×1 | 100刻，5秒 |
| 止血蓍草×3 | 蓍草敷料×2 | 无 | 药草残渣×1 | 100刻，5秒 |

所有配方每批固定损耗研钵1耐久，耐久附魔不免除此损耗。最后1耐久仍完成本批，随后破碎。

同料可以分散在三个原料槽，多余同料保留；混入无关原料不匹配。放齐后自动加工，不提前扣材料。所有本批需要的输出槽能容纳时才原子提交；任何所需输出堵塞则保留进度暂停，无对应输出的槽不必清空。

更换工具或取走必要材料会清零，追加同种且仍有效的原料不清零。输出变化不清零。界面关闭后继续工作；区块卸载暂停，重新加载验证后继续，不补现实时间。

第一版不提供物品能力接口，不支持漏斗自动化。菜单依靠服务端距离和方块存在校验；打开人数不增加加工次数。

## 扩展配方

- 配方类型与序列化器：`white_lily:simple_processing`。
- 正式配方：`data/white_lily/recipes/processing/`。
- 相同输入匹配多份配方时，使用完整配方 ID 的字典序，最小者优先。
- 例子：

```json
{
  "type": "white_lily:simple_processing",
  "tool": { "item": "white_lily:stone_mortar" },
  "tool_damage": 1,
  "ingredients": [
    { "ingredient": { "item": "white_lily:hemp_stalk" }, "count": 1 }
  ],
  "result": { "item": "white_lily:plant_fiber", "count": 2 },
  "processing_time": 40
}
```

可选 `container` 与一项带数量的原料格式相同；可选 `return`、`byproduct` 与 `result` 相同。产物允许配方 NBT，合并时检查物品和 NBT。最多16项原料要求、合计不超过192件；机器每槽不超过物品上限与64中较小值。时间为1～32767刻，以适配原版菜单属性同步；工具损耗为1～128。

保存中包含库存、进度、配方 ID、完整配方指纹与工具快照。`/reload` 后已删除或改变的配方安全重新计时，不会将旧进度套给新产物。
